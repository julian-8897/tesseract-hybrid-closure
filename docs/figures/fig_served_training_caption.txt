A-posteriori training in which every forward evaluation and every gradient crossed the two separately built, separately served Tesseract images over HTTP. Left: the two-step rollout vorticity MSE for each of 500 Adam updates, one train-split trajectory per update, with a 20-update running mean; the run issued 500 served solver VJP calls and 1000 served closure VJP calls, and all 822,977 gradient entries stayed finite throughout. Right: 30-step vorticity MSE on eight held-out validation seeds (10000-10007), comparing the fixed initialisation the run started from, the closure this served run produced, and the submitted model trained in process for 700 updates with a 1 -> 5 -> 30 unroll curriculum, all scored identically. This is a demonstration that the deployment boundary sustains genuine optimisation; it is not the submitted model, and no reported result depends on it.
